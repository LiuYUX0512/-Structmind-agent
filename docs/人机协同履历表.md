## 项目分工与 AI 参与环节、修改验证过程

**分工**：本人负责创意与需求定义、结构专业知识把关、工程正确性复核、现场演示答辩；AI（豆包）负责系统架构设计、代码实现、视觉设计、自动化测试与部署；AI（DeepSeek 等）负责第三方评审建议。

**AI 参与环节**：需求定义（人机共创）→ 方案架构（AI 主导设计，人工确认"大模型不参与数值计算"底线）→ 编码（AI 完成）→ 验证（AI 自动化 11 场景 48 断言 + 人工抽检）→ 视觉（AI 按"顶级美学"标准迭代 5 批）→ 部署（AI 完成双分支发布）→ 答辩材料（AI 起草、人工修订）。

**修改验证过程**：每一批改进都遵循"AI 改 → 全量回归（typecheck/lint/主回归/专项 48 断言）→ 线上核验 → 人工复核"闭环；涉及结构计算的修改一律由本人按现行规范人工复算确认后才上线；历次修改均有 git 提交记录可追溯。
