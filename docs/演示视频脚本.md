## 录制提示

1. **环境**：电脑 Chrome/Edge 打开线上链接（手机需先清缓存，确保是最新版）；分辨率建议 1920×1080 或 1280×720。
2. **节奏**：每镜操作前先停顿 0.5 秒再操作，方便后期剪辑；若超时可压缩镜 3 与镜 7 的展示细节。
3. **语音**：按解说词念即可，语速平稳；也可用剪映"文本朗读"生成语音再配字幕（更稳）。
4. **检查**：导出 MP4 后自查——能看清界面文字、语音清晰、总时长 ≤2 分钟、无卡顿黑屏。
