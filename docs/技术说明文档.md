# 智构 StructMind · 建筑结构方案优化 AI 智能体

## 作品简介

面向建筑方案阶段的多 Agent 协同结构选型与优化工具：输入层数、面积、跨度、设防烈度等工程参数，自动生成多套候选结构体系，完成规范逐条校核、七维量化比选与综合推荐，让工程师在方案阶段快速获得可溯源、可干预的多目标寻优结果。

# 1. 背景与场景

## 1.1 目标用户

- **主用户**：建筑结构设计工程师（含在校土木/结构专业学生与青年教师）。
- **用户特征**：年龄 22~45 岁，具备结构概念设计基础；日常使用 PKPM、YJK 等专业软件，熟悉现行国标（GB 55002、GB 50011 等）；对 AI 工具有一定了解，但缺乏编程能力，希望 AI 介入"方案阶段"而非"施工图阶段"。
- **数字化能力**：中等偏上，可流畅操作图形化软件，但对命令行、API 配置等门槛敏感。

## 1.2 用户痛点与问题定义

- **痛点**：结构方案阶段（概念选型）高度依赖工程师经验——同一栋建筑选框架还是剪力墙、柱网怎么布、跨度取多少，通常靠"拍脑袋+查手册"，多方案比选耗时且易遗漏。
- **具体场景**：方案阶段要在 1~2 天内给甲方/评审会拿出 3 套候选方案及对比结论，传统做法是逐方案手算试算、对照规范逐条自查，通常需 1~2 周。
- **现有解决方式的不足**：PKPM/YJK 等专业软件定位在"详细设计校核"，建模门槛高、不适合方案阶段快速试错；通用大模型会"一本正经地算错结构"（幻觉），无法保证规范符合性，且回答不可溯源。
- **要解决的核心问题**：① 方案阶段多方案快速生成与比选；② 规范符合性的可信判定；③ 全流程推理可溯源、可人工干预。

## 1.3 使用场景

- **场景一（快速寻优）**：建筑师给定"8 层办公楼、面积 8000㎡、跨度 8.4m、设防烈度 7 度、预算 1.2 亿"，工程师在系统中生成 3 套候选体系（框架/框架-剪力墙/钢结构），一键完成抗震、耐火逐条校核与造价、碳排对比，10 分钟内获得推荐方案与风险提示。
- **场景二（人机协同纠偏）**：工程师认为推荐方案造价偏高，在"专家干预面板"锁定结构体系、设定预算上限后重跑，系统在约束内重新寻优并给出满足预算的新方案；任一判定均附规范条文号，可点击溯源。

## 1.4 价值体现

- **效率提升**：方案比选由"周"级缩短到"分钟"级，多方案并行生成与对比。
- **决策可信**：数值计算由确定性规则引擎完成，规范校核逐条附条文号，杜绝大模型幻觉。
- **协同增强**：Human-in-the-loop 机制，工程师可锁定参数、设定预算、注入备注，AI 在约束下寻优。
- **学习辅助**：完整的推理轨迹时间线（思考→查规范→判定→重算）对在校生是极佳的结构概念教学素材。

# 2. 功能说明

## 2.1 核心功能

| 功能 | 用户输入 | 处理方式 | 输出结果 | 解决的问题 |
|---|---|---|---|---|
| 方案智能生成 | 层数/面积/跨度/烈度/预算/结构类型偏好等 | 意图理解 Agent 解析补全 → 创作 Agent 生成候选体系与初始截面 | 3 套候选方案（体系/截面/配筋率/挠度等） | 快速多方案试错 |
| 规范自动校核 | （方案生成后自动触发） | 规范校核 Agent 按 GB 55002/GB 50011 等逐条硬判定 | 通过/警告/失败 + 限值对照 + 条文号 | 规范符合性可信判定 |
| 七维综合比选 | 权重偏好（可调） | 经济评估 Agent 量化造价/工期/碳排 → 总工 Agent 加权评分+辩论+反思 | 雷达图对比 + 推荐方案 + 置信度/风险 | 多目标权衡决策 |
| 智能问答 | 自然语言结构问题 | 意图归一 + 知识库检索 + LLM 组织回答 | 结构化专业回答 | 方案阶段知识咨询 |
| 专家干预（HITL） | 锁定方案/预算上限/强制权重/备注 | 注入下一轮管线约束 | 约束下重算的新结果 | 人机协同纠偏 |
| 历史版本管理 | 一键存档/对比 | localStorage 保留最近 10 版 | 任意两版参数与结果 diff | 方案版本留痕 |
| 报告/模型导出 | 一键导出 | 打印样式 PDF 报告 / PKPM 前哨模型文件 | PDF 优化报告 + 建模文件 | 交付物落地 |

## 2.2 技术方案

**整体流程**：用户输入工程参数 → 意图理解 Agent（LLM 解析+规则补全）→ 方案创作 Agent（候选体系生成，LLM 只做选型推理）→ 规范校核 Agent（**确定性规则引擎**逐条判定，不依赖 LLM）→ 经济评估 Agent（造价/工期/碳排系数库量化）→ 总工评审 Agent（反思 + 多 Agent 辩论 + 加权仲裁）→ 输出比选结果/校核报告/问答。

**关键设计（大模型不参与数值计算）**：大模型仅承担"调度员/翻译官"——意图解析、自然语言问答、选型解释；所有数值计算（内力估算、配筋率、挠度、位移角、碳排系数）由硬编码规则引擎（TypeScript 实现）执行，从架构上杜绝"AI 拍脑袋算结构"。

**提示词与交互设计**：为四个 Agent 分别设计了角色设定（方案创作工程师/规范校核工程师/经济评估工程师/总工评审）、任务指令、结构化输出格式（JSON schema）、异常提示（参数缺失追问、预算超限回退）与多轮追问（意图置信度低时反问澄清）。

**知识库**：内置土木工程专业知识库——规范条目数据库（JSON：GB 55002、GB 50011、GB 55008、GB 55037 等条文号+条文原文+适用范围+校核逻辑引用），碳排放因子库（GB/T 51366 分阶段因子）；每条判定输出均携带条文号，点击可展开原文，结论可追溯。

**工作流与工具调用**：自研多 Agent 状态机管线（意图 → 创作 → 校核 → 评估 → 总工），支持回退重算（校核失败→打回创作 Agent 重出方案）、辩论机制（校核 Agent 与创作 Agent 交锋，总工仲裁）、崩溃降级（真实模式异常自动降级演示模式）。

**部署方式（自主开发）**：前端 React 19 + TypeScript + Vite（纯前端 SPA），GitHub Pages 发布，手机/电脑浏览器直接访问；LLM 安全代理层为 Vercel Serverless Function（`/api/chat`），API Key 仅存服务端环境变量，前端零暴露，含频率限制与参数白名单。

## 2.4 创新与差异化

1. **"大模型只做调度、规则引擎算结构"**：针对结构设计领域最致命的幻觉问题，架构上隔离推理与计算，规范校核走确定性 if-else 规则引擎——区别于"纯 Prompt 套壳"的伪智能体。
2. **多 Agent 真实协同**：状态机 + 回退闭环 + 辩论仲裁，而非线性 Prompt 串行；评委可见完整"思考-查规范-判定-重算"轨迹。
3. **Human-in-the-loop 贯穿**：预算上限、方案锁定、权重强制、备注注入，AI 在工程师约束下寻优，最终决策权始终在人。
4. **可追溯的规范校核**：每条判定附条文号 + 原文，点击溯源；知识库以结构化逻辑判断树组织，而非模糊向量检索。
5. **工程交付物闭环**：一键导出 PDF 优化报告与 PKPM/YJK 前哨建模文件——定位"专业软件的智能前端"而非替代者。

## 2.5 作品完成度

**已完成**：多 Agent 管线全流程、规范校核规则引擎（抗震/耐火/位移/承载）、七维比选与雷达可视化、3D 结构线框（可拖拽旋转/滚轮缩放/违规构件红色警示）、专家干预面板、历史版本对比、PDF 报告导出、PKPM 前哨导出、意图归一与澄清、运行时验证页（内置 11 场景 48 断言自动化体检）。

**不足与后续方向**：① 规范覆盖广度（当前聚焦抗震与耐火强条，后续扩展荷载、地基基础等章节）；② 与专业软件的深度对接（当前为前哨文件格式，后续研究 PKPM 接口）；③ 3D 可视化目前为自研 SVG 等轴测线框，后续可在保持性能的前提下增强构件级交互；④ 计算模型采用经验公式与简化假定，需在界面显著位置声明"仅方案阶段参考，最终设计须注册结构工程师复核"。
