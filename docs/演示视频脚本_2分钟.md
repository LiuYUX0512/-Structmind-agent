## 镜头 1｜0:00 – 0:15｜痛点切入（不自我介绍）

**【画面】** 浏览器打开应用首页，定格 Hero 区（大标题 + 三个能力徽章 + 右侧能力雷达）。

**【鼠标操作】** 打开首页 → 停 2 秒 → 鼠标依次划过「动态规划引擎 / 主动记忆系统 / 元认知自进化」三个徽章（触发悬浮解释）。

**【配音逐字稿】**
"方案比选阶段，造价、工期、碳排放多目标相互冲突，人工计算加 PKPM 逐方案试错，一轮下来要好几天。这是智构 StructMind——给结构工程师的一个 AI 虚拟工程部。"

**【字幕要点】** `多目标冲突 · 校核繁琐 · 比选难量化`

## 镜头 2｜0:15 – 0:45｜输入参数 → Agent 时间线流转

**【画面】** 滚动到参数面板 → 修改参数 → 点击「生成方案」→ Agent 执行时间线开始滚动。

**【鼠标操作】**
1. （0:15）参数面板：层数改 **30**、设防烈度 **8 度**、主跨度 **9m**；
2. （0:25）点击 **生成方案** 按钮；
3. （0:30）鼠标移到 Agent 时间线，跟随滚动，让四个 Agent 卡片依次点亮。

**【配音逐字稿】**
"输入一个真实的工程场景：八度设防、三十层、大跨度，点击生成。四个智能体立即协同开工——方案创作、规范校核、经济评估，每一步思考、每一次工具调用，全部实时可见，而不是一个黑盒。"

**【字幕要点】** `4 Agent 协同 · 全过程可溯源`

## 镜头 3｜0:45 – 1:15｜★高潮：多 Agent 辩论与打回重做★

**【画面】** 切到「思维导图」视图（AgentFlowMap 执行图），红色「打回重算」弧线出现；再切回日志看 Code 的违规判定原文。

**【鼠标操作】**
1. （0:45）点击时间线上方的 **思维导图** 切换按钮；
2. （0:50）鼠标**沿红色弧线从 Code 画回 Architect**，停留 2 秒（弧线上有动态标签，如"发现 3 条强条违规：层间位移角/剪重比/最大适用高度"）；
3. （1:00）切回「明细」视图，滚动到 Code Agent 的校核结果（层间位移角 fail / 剪重比 fail，附条文出处）；
4. （1:08）继续滚动到 Architect 携带反馈重新选型的日志。

**【配音逐字稿】**
"重点来了——Code 智能体逐条核对规范，发现框架结构层间位移角、剪重比不满足强制性条文，**直接打回给 Architect 重新选型**，这就是系统的自我纠错。注意每条判定都附带规范条文原文，可追溯、可复核。经过辩论与复核，方案自动收敛到合规解，最后由总工 Agent 一锤定音。"

**【字幕要点】** `强条违规 → 自动打回 → 重新选型 → 总工仲裁`（红色弧线出现时字幕同步高亮）

## 镜头 4｜1:15 – 1:35｜★能力雷达 + DAG 电影模式★（本次新增）

**【画面】** 首页 Hero 区右侧能力雷达（六边形，数值随真实运行波动）→ 点击「15 秒看懂」进入 DAG 电影模式全屏。

**【鼠标操作】**
1. （1:15）鼠标指向 **能力雷达**，依次划过六个顶点（悬停弹出"分子/分母 + 数据来源"，如"硬计算密度 34/50 条日志为工具调用"）；
2. （1:25）点击 Hero 区「**15 秒看懂**」播放按钮 → 进入全屏电影模式；
3. （1:28）画面自动播放：节点依次点亮、红色打回弧线出现、总工仲裁收束（右下角标注「📽️ 真实回放」）。

**【配音逐字稿】**
"系统还能自证能力——这张雷达图的每一个顶点，都绑定本次运行的真实指标：DAG 节点数、记忆命中数、反思条数、确定性工具调用占比。点击'十五秒看懂'，整个执行过程自动回放成一段电影，从方案创作到打回重做、再到总工仲裁，一镜到底。"

**【字幕要点】** `能力自证（指标可点击溯源） · 15 秒 DAG 全流程回放`

> **录制提示**：若雷达分值偏低（离线演示轨迹较短），可先切到「示例项目」高亮案例——首屏默认加载八度五十层智能办公楼的完整轨迹，雷达六维饱满、电影模式镜头更完整。
